Database optimize

When enabled, the repair operations are really executed on the database. When disabled (default), the task only writes to the log every operation it would execute and the reason why it is needed, and nothing is changed in the database. Use it for a first debug run.
Copies the database to the backup folder right before the repair, only when problems were found and "Execute operations on the database" is enabled. If the backup fails, the repair is not executed.
Absolute path of the folder that receives the backups. The timestamp of the run is added at the end of the file name, for example jellyfin_20260101-030000.db. The folder is created if it does not exist.
